## 1. 项目中的“顶级宋朝审美”定义

不是把画面统一做成灰白、空无、贫素，也不是复制某幅宋画或堆叠宋代符号。项目统一采用六字审美核：

```text
清｜雅｜简｜远｜润｜真
```

- **清**：主次、结构、光向和材质关系清楚，画面没有视觉噪声。
- **雅**：色彩、装饰和情绪节制，以比例、留白、材质和气韵取胜，不以豪奢炫技取胜。
- **简**：减少无叙事价值的元素，但保留准确的结构与生活依据；“简”不是空洞或粗糙。
- **远**：通过水面、天空、烟岚和层叠远山形成画外余意，使有限画面产生纵深与时间感。
- **润**：巴蜀湿润空气、温和天光、低亮织物、木石水汽和古玉温润感统一；避免干硬锐化。
- **真**：建筑受力、服装层次、材料老化、人物身份与场景生活逻辑真实可信。

总方法为：**精确写实＋诗性删减；实处极准，虚处敢留；材料比装饰重要，气韵比信息量重要。**

## 2. 场景母图的宋式空间语法

### 2.1 每张母图必须具备的八项结构

1. **一个主构图命题**：每张母图只设一个第一视觉锚点或一个主关系组，不平均分配注意力。
2. **非对称平衡**：优先偏侧、半边、边角入画和斜向展开；禁止旅游照式居中对称，剧情或建筑轴线确需对称者除外。
3. **三层空间**：近景可触材料锚点＋中景烟岚/水面间隔＋远景山体/天空收束。
4. **虚实相生**：水、雾、天光和暗部是构图结构，不是后加特效；安静区域通常占画面30%—60%，按场景矩阵执行。
5. **疏密有序**：细节集中在叙事锚点附近，离开锚点后逐级简化；不得全画面同等锐利、同等密集。
6. **近实远虚**：近景材质准确，中景轮廓归组，远景以空气透视和柔和边缘后退；禁止把每片叶、每块石都做成高清纹理。
7. **人景有序**：母图默认空场；场景资产不得随机加入人物、船、灯笼、摊位、飞鸟等“增添生气”的模型惯性元素。组合资产中人物应小于山水与建筑秩序。
8. **可拍摄性**：必须留出真实站位、行动路径和光线进入方向；留白不是堵死的空白，而是可以承载表演和调度的空间。

### 2.2 北宋与南宋空间语法的分工

- **北宋式山水秩序**用于神话山湖、九龙水法岩壁、山城防线：山体和地貌建立宏观等级，人和建筑服从自然尺度；宏大但不奇观化。
- **南宋式边角诗境**用于龙水湖青石岸、临水廊亭、三孔桥水岸、祈福树：主体偏侧，大片水面、烟岚或天空形成余韵，以少胜多。
- **《清明上河图》式生活观察**用于战乱街巷、桥岸交通与民生细节：结构和日常可信，但只保留剧情需要的区域，不把整座城市和全部市井信息塞进一张母图。

### 2.3 场景母图固定检查句

每条场景母图Prompt在完成具体空间描述后，必须落实以下含义，可按场景改写但不得缺项：

```text
采用宋画式非对称空间组织与虚实相生关系，以一个主视觉锚点统领画面；水面、烟岚、天空或暗部作为大块安静空间，近景材质准确，中景轮廓归组，远景随空气透视柔化。建筑、道路、植被和生活物件服从真实尺度与场景功能，不作旅游照式居中对称，不以摆满元素表现“古意”。
```

## 3. 南宋建筑与场景材料

1. 建筑先表现木构受力与模数秩序：柱、梁、枋、斗栱、屋架、门窗和屋面关系清楚；不得只贴“宋代建筑”标签。
2. 巴蜀民居与普通廊亭以深旧木、灰瓦、灰白或土色墙面、自然石基和夯土为主；构件尺度克制，屋檐轻而有出挑。
3. 宫殿、寺观和高等级建筑可出现青绿、朱、白、黑等分层彩画，但颜色必须服从等级与构件，不满铺金色，不做明清宫殿式琉璃金龙和巨型繁密斗栱。
4. 宋代并非只有灰色。民居偏质朴，高等级建筑可有克制的青绿和朱色；色彩差异必须来源于建筑等级与功能。
5. 园林与水岸采用“简远、疏朗、雅致、天然”的组织：少分区、少品种堆砌、少人工奇石陈列；人工构筑与外部湖山相接。
6. 石、木、瓦、土、布和水体以大块材质关系呈现；禁止高频裂纹、满墙雕花、满地小石、到处青苔和统一做旧滤镜。

## 4. 人物服装与发型造型

### 4.1 共同规则

1. 服装高级感来自轮廓、裁剪、层次、垂坠、织物和身份准确，不来自配饰数量。
2. 保持纵向、修长、克制的宋式轮廓；外层、内层、腰束和下摆关系清楚，长裙或长袍按当前项目锁定遮住脚背。
3. 纹样优先采用低对比暗纹、织纹、窄幅缘饰或小型自然花卉；每套只保留一至两个纹样逻辑。禁止大面积金绣、密集团花、仙侠流苏和无身份依据的华丽甲饰。
4. 材料优先绢、罗、纱、绫、苎麻、细麻等真实织物观感；表面低亮、轻薄或温润，禁止塑料光泽、硬壳布料和过度锐利褶皱。
5. 发型按身份、场合与服装改变，结构必须能真实束扎；禁止巨大高冠、复杂仙髻、过多发饰和现代影楼式碎发造型。

### 4.2 林如蔚

- 日常与乡野身份不强制宫廷背子，但保持窄长、清柔、易行动的宋式层次；袖量和裙幅克制，不做唐式宽大团花，也不做仙侠飘带。
- 可使用浅青、浅蓝、月白、米杏、茶褐、浅藕紫等低至中低饱和色；小面积暗红或花色只作缘饰和情绪节点。
- 已登记服饰参考仍按“服装、发型、穿戴配饰整体继承，脸部不继承”执行；主创已明确删除的竹篓、斜挎带和腰间配饰不得恢复。
- 冷珠仍按最新规则颈戴，不以增加其他首饰制造“精致感”。

### 4.3 苏珏

- 常服以交领、窄幅直身长袍、层叠内外襟、宽窄有序的腰束和长下摆构成；185厘米严格九头身，纵向比例不能被过宽肩袖和厚重腰挂破坏。
- 可使用冷浅青米灰、茶褐苔绿、月白云灰、深蓝灰与灰褐轻甲等错开色系；深褐可作为真实宋代男装颜色，但不得整套纯黑。
- 轻甲强调可动、克制和基层身份：短护片或札片服从深蓝灰窄袖长内袍，不做将帅金甲、战神肩甲或游戏盔甲。
- 暖珠仍在左腕按袖口真实显隐；无挎包、行囊、腰挂物和替代容器。

## 5. 宋式色彩、光泽与影调

### 5.1 基础色群

```text
天青｜粉青｜月白｜香灰｜米杏｜茶褐｜苔绿｜墨青｜旧木褐
```

小面积强调可用：低纯度朱砂、暗绛、青绿。禁止：霓虹青绿、高纯度大红大紫、通体金色、仙侠冰蓝和无物理来源的艳色轮廓光。

### 5.2 影调方法

- 使用自然天光、侧光、侧逆光、廊柱阴影、云层漏光、湖面反光和湿润空气散射。
- 高光不爆白，暗部不死黑，中间调保留织物、木石和肤质层次。
- 参考宋瓷“以形、釉、色与温润材质取胜”的方法：表面有细微层次，但不以刻花、裂纹和装饰数量抢眼。
- 画面总体低至中低饱和，但必须有冷暖与明度层级；禁止把“宋韵”处理成统一灰滤镜。

### 5.3 2026-07-17场景母图青绿影调覆盖

- 九场`V-MASTER`统一使用青绿影调作为项目色彩母语：墨青、黛绿、深苔绿和蓝黑构成阴影；石青、天青、粉青、灰绿与旧木褐构成中间调；月白、银青与珍珠白构成高光。
- 各场允许5%—12%的铜金、暗赭、琥珀或低纯朱砂作为叙事节点，但不得把暖色铺满天空、水面或建筑。
- 青绿影调必须由天空、水汽、湖面反射、湿木、青石、苔藓与综合色彩分离共同形成，不得直接覆盖统一青色滤镜。
- 场景母图不得使用中性阴天白平衡、平均曝光或HDR抬亮暗部；阴影允许比主要亮面低两至三档，前提是仍保留大块材料层次。
- 每场应有独立青绿变体：神话山湖偏墨青与珍珠金；殿宇偏蓝黑、冷青与微琥珀；岩壁偏石青与苔绿；山城偏铁黛绿与暗赭；湖岸偏粉青与银青；街巷偏灰绿与茶褐；廊亭偏墨青木影与银青湖光；石桥偏深黛与铜金；祈福树按四季在青绿母调内变化。

### 5.4 2026-07-17场景非人物叙事元素覆盖

- 场景母图只排除人物、人物剪影、人物占位和群演，不排除剧情中应有的动物、神兽、载具、道具、文字层或环境VFX。
- 对应场次已登记的九龙、双珠、水汽、白鹭、小舟、军旗、烽烟、书卷、竹篮、征募文书、布包木箱、灯笼、渡船、缆绳、祈福红绸、荷叶与薄雪必须直接进入MASTER，并受同一青绿光场作用。
- 固定非人物元素在方向视图和季节变体中保持位置、数量、结点、文字与状态连续；动态动物和神兽允许姿态变化，但数量、远近层级与活动区域不得漂移。
- `SCN-007`临水古廊亭固定使用正好5只高低错落白鹭：低飞2只、中景2只、高飞1只；另有一艘极小远舟和一盏低亮旧布灯笼。
- `SCN-009`祈福树读取`QNXY-REF-024`作为红绸家族的材质、结点、受风与旧化基线；整树主枝、次级横枝和下垂细枝必须密集挂满数十至上百条祈福红绸，形成近大远小、上密下疏、成簇错落的三层红绸群。林如蔚的主叙事红绸固定同一低枝与结点，正文始终为“愿战事平息，四海清平，良人早归。”且不加落款；其他红绸只显示不可辨墨痕。春季满枝湿红绸自然垂落、夏季整树受风展开、秋季分层褪色且主绸重系、冬季满枝旧红绸与薄雪并存、多年后旧愿与少量新愿叠加。满树红绸必须归并为簇群节奏，不得做成现代景区塑料带、整齐排队或高频纹理噪点。
- 禁止把“无人场景”制作成“无动物、无船、无道具”的空环境；也禁止为了热闹加入无剧情依据的随机元素或把所有元素同等突出。

## 6. 地域与阶层校准

1. 本项目是**南宋巴蜀**，不是把临安宫廷、江南园林或博物馆器物直接搬进龙水湖。
2. 宋代绘画提供空间和取舍方法；巴蜀湖山、湿润山雾、山城地貌、土石木构和地方生活提供内容。
3. 宫廷、士人、乡野、军旅的建筑、衣料、色彩和装饰必须分级；不得所有角色都穿文人雅集服，也不得所有建筑都按宫殿等级设计。
4. 历史可信度优先于“古风辨识度”；出现时代不明或明清化元素时，宁可删减，不以装饰掩盖结构错误。

## 8. 研究依据与项目转译说明

- 故宫博物院对宋画的概述指出，南宋山水由全景式转向边角式，以简练景物形成完整意境，并强调诗画结合：[宋代绘画简介](https://minghuaji.dpm.org.cn/page/detail?dynasty=21&id=10)。
- 夏圭作品以近景占画面一隅、远山隐于大面积烟霭的方式建立开阔空间：[《遥岑烟霭图》](https://minghuaji.dpm.org.cn/paint/detail?id=5b844b6a04034129aee211ea0fae852a)。
- 马远作品体现实体与无边空白、明暗之间的平衡：[Viewing Plum Blossoms by Moonlight](https://www.metmuseum.org/art/collection/search/44638)。
- 《营造法式》以材料、模数、构件和工序建立宋代建筑秩序，并非单一装饰风格：[中国国家博物馆《营造法式》](https://www.chnmuseum.cn/zp/zpml/gjwxbt/202203/t20220301_254037.shtml)。
- 南宋女性背子、裙与鞋的实物资料呈现窄长、开衩、缘饰克制的服装结构：[中国丝绸博物馆“素罗单衣”](https://www.chinasilkmuseum.com/cs/info_164.aspx?itemid=28354)。
- 宋瓷以素雅、清丽、少刻意雕琢的形与釉色见长：[中国国家博物馆“汝窑天青釉洗”](https://www.chnmuseum.cn/zp/zpml/csp/202203/t20220307_254173.shtml)。

上述资料只用于提炼空间、材料、结构和取舍原则；不得直接复制具体名画构图、古建实例或出土服装图案。

## 9. 阶段2B验收口令

每个视觉资产Prompt交付前必须回答：

1. 第一视觉锚点是什么？
2. 哪一块是有意义的“虚”，占比是否足够？
3. 近、中、远是否真正分层？
4. 建筑与服装的结构是否比装饰更可信？
5. 色彩是否有层级，而不是统一灰？
6. 是否存在可删掉而不影响叙事的古风装饰？若有，删除。
7. 是否出现明清化、仙侠化、旅游照化或纹理堆砌？若有，退回重写。
