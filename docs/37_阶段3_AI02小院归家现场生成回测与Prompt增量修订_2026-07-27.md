## 2. 全局现场修订规则

1. Prompt继续使用正式模板中的固定顺序：`资产参考`、`画面质感`、`镜头结构`、`镜头正文`、`同期声`、`光线规则`、`不要字幕，不要音乐`。
2. 所见即所得。人物位置、院内外关系、船头船尾、屏幕方向、景别、运动起点和运动终点必须直接写入镜头正文。
3. 所有湖山镜头都必须存在细微而分层的实时环境运动：湖面涟漪、倒影变化、山间薄雾、天空薄云、不同距离的树叶与花草分别以不同幅度、不同速度、不同步运动。
4. 人物情绪不能只写“温和、克制、轻缓”。男主归家状态必须同时包含旅途后的轻微疲惫、见到女主后的欣喜、肩背放松和安心笑意；女主必须同时包含久候后的喜悦与看见男主风尘后的心疼。
5. 白鹭行为需要分成飞行个体与停栖个体。停栖白鹭不能全部飞走，应通过转头、理羽、伸颈、换脚、移动一至两步、短暂展翅后收拢等错峰小动作保持生命感。
6. 空气细尘属于可保留的真实微观氛围，不作为污染项删除。只在小院斜射或侧逆夕阳形成的局部光束中出现极少量细小尘粒，稀疏、缓慢、间歇可见；不铺满画面，不形成烟雾、灰霾、闪粉或仙侠粒子。
7. `@小院林如蔚01.png`、`@竹椅.png`与`@橘猫.png`保持三个独立资产，不生成、不登记人物坐椅抱猫合成图。G06在镜头Prompt中直接调用三个独立资产，明确人物落座、双臂抱猫、衣裙与座面接触、猫的自然微动作和摇椅极轻缓摇动。
