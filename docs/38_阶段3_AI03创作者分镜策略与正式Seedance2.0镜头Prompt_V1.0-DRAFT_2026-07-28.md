## 1. 创作者核心思路

### 1.1 戏剧结构

本段不是普通的“战乱蒙太奇＋情侣告别”，而是一次由外向内的压力收束：

```text
山河受压
→ 街巷失序
→ 一张文书进入苏珏手中
→ 苏珏作出个人选择
→ 他把选择带到林如蔚面前
→ 林如蔚边回应边靠近并抓住他的衣袖
→ 苏珏把她抱入怀中并承诺归来
→ 一滴泪落下，摄影机退回廊亭与雾中湖山
```

因此视觉节奏采用“动—静—更静”：

- 防线与街巷：画面信息密度高，人物运动方向交错，剪辑较短。
- 苏珏接文书：突然收紧到双手、纸张背面和人物表情，外部人群声逐步降低。
- 廊亭对白：通过廊柱横移显露、人物侧前方小幅环绕、动作近景与缓慢推近，让摄影运动跟随迟疑和靠近。
- 最终收束：苏珏抱住林如蔚并贴耳承诺归来；林如蔚只落下一滴泪，摄影机真实后移并轻微升高，让拥抱二人与廊亭、四盏灯笼、雾中湖山共同结束本段。

### 1.2 视点设计

- 防线段使用旁观者视点：观众看到的是时代压力，不进入具体战斗。
- 街巷段使用苏珏即将进入的现实视点：先看现有群众和义士，再让苏珏进入递交位置。
- 文书阅读使用苏珏内心视点：纸面背向镜头，观众从他的表情理解内容，不依赖文字。
- 廊亭段逐渐转为林如蔚视点：林如蔚认出苏珏时先温暖微笑，随后看见他的迟疑，边说边走近并抓住左侧衣袖。
- G08落泪镜完全进入林如蔚面部视点，右眼和右侧脸成为唯一清楚主体；最后恢复环境视点，以真实后移看见拥抱二人和整座廊亭。

### 1.3 表演方向

- 苏珏不是慷慨激昂，而是已做决定却难以向爱人开口。情绪通过呼吸、喉结、眼尾和握纸力度表现。
- 林如蔚不是被动承受。她先完成观察和理解，再一边说出完整对白一边慢慢靠近，以抓紧苏珏衣袖的动作显出语言之外的依恋和不舍。
- 苏珏不举起征募文书说话；文书始终垂在右腿外侧，拥抱后停在林如蔚腰后外侧。
- 二人的爱意建立在熟悉、通透和克制上；拥抱明确有重量，林如蔚搂紧苏珏腰部，但不使用奔扑、哭喊、亲吻或连续落泪。
