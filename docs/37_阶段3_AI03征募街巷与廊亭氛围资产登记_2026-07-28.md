## 4. AI-03文书与人物调度锁定

```text
街巷群像建立
→ 义士呼喊、贴告示、递交文书，青壮停步，逃难百姓继续通过
→ 苏珏进入中左递交位置
→ 发文书义士把一张平整征募文书递给苏珏
→ 苏珏接稳
→ 单切苏珏持文书阅读的近景表情
→ 文书纸面不向镜头展示
→ 苏珏带着同一张文书离开街巷
→ 进入廊亭段后文书逐步被攥出折痕
```

禁止事项：

- 不把图中原接收文书者变成苏珏。
- 不在苏珏阅读近景中展示或新增可读征募文字。
- 不让同一张文书在贴墙、递交、手持与攥皱状态之间改变纸色、尺寸、毛边和朱印位置。
- 不把街巷群众改成披甲军队、武侠帮派或近身厮杀人群。
- 不让逃难者、义士和青壮全部做同一种同步动作。
