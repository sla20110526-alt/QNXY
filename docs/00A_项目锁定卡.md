## 3. 已锁定的剧本忠实性口径

1. 画外独白、画外音必须进入分镜正文，并随 AI 视频生成。
2. 原台词逐字保留，不压缩、不润色、不改写；允许在多个镜头中连续承载，但不得改变台词顺序。
3. 西子湾离别场景使用南宋风三孔石桥。历史资料中的“单孔旧石桥”“禁止三孔桥”全部废止。
4. 石桥离别的固定叙事顺序为：
   - 林如蔚说：“宝珠换作念想，我就守着这片湖山，日日祈愿，盼你平安归来。”
   - 苏珏伸手想碰她的指尖，在半空停顿，最后轻轻握住 / 覆住她的手腕与手背；该触手动作不再绑定冷珠佩戴位置。
   - 苏珏说：“战事凶险，倘若此生无缘再见，便以双珠为契，来世再续前缘。”
5. 追船段必须保留林如蔚沿湖岸挥手追船，以及追至尽头后弯腰、手掌压在膝上的关键动作。
6. 四季等待采用同一祈福树、同一湖岸和固定摄影机位，但人物服装、姿态和动作按原剧本变化：

   - 夏：轻薄夏装，外层减少，坐在树下，冷珠项绳仍戴在颈部，望向湖面。
   - 秋：廊亭告别常服加薄披，仅留素簪，重新系紧松开的红绸。
   - 冬：灰白冬装外氅，薄雪、冷雾和轻微呼吸白气。
   - 暮年：同一人物自然老化，白发木簪、素净衣色，冷珠项绳仍戴在颈部，望湖。
7. 固定机位只锁定摄影机、祈福树、湖岸和远山关系，不要求人物在春夏秋冬始终固定于同一站位。
